# 活动生产平台与飞轮合作需求

我们负责把活动生产出来，飞轮负责让活动稳定运行并上线。

## 一、背景

目前活动上线需要经历：

**业务提需求 → 设计出图 → 人工切图 → 飞轮配置 → 测试上线**

页面素材和活动配置存在大量重复处理。遇到多种交互状态、人群差异或动效时，沟通和配置成本会进一步增加。

因此，希望打通我们的活动生产平台与飞轮，减少人工操作，提高活动上线效率。

## 二、我们是什么

我们是一个面向 H5 营销活动的**智能生产与可视化编排平台**。

| 输入 | 平台处理 | 输出 |
|---|---|---|
| 业务需求、PRD、活动规则 | 组件搭建、视觉编辑、状态配置、人群配置 | 页面预览、切图素材、组件参数、活动配置 |

平台支持头图、任务、权益、抽奖、弹窗等活动组件。

我们的定位是活动生产链路的上游工具，不替代飞轮的任务、抽奖、发奖、发布和线上运行能力。

## 三、共同目标

| 当前情况 | 共同目标 |
|---|---|
| 人工逐张上传切图 | 素材可以自动交付并绑定 |
| 活动配置重复填写 | 配置可以直接导入飞轮 |
| 页面效果依赖静态图片 | 支持组件、状态和动效 |
| 不同人群重复搭建页面 | 支持人群差异化配置 |
| 两个平台产物无法复用 | 建立统一的活动交付标准 |

## 四、希望的合作关系

我们希望与飞轮形成长期的平台协作关系，而不是每次活动临时沟通和人工搬运。

| 角色 | 主要职责 |
|---|---|
| 我们 | 理解业务需求，完成页面设计、组件编排、素材生成和配置整理 |
| 飞轮 | 承接活动内容，提供任务、抽奖、发奖等业务能力，并负责发布和线上运行 |
| 双方共同 | 定义素材、组件、配置和代码的对接标准，并持续维护 |

## 五、需要共同讨论的需求

### 1. 交付方式

| 需求 | 说明 | 合作方式 |
|---|---|---|
| 自动交付切图 | 减少逐张上传、选择坑位和替换素材 | 我们输出规范素材和对应关系，飞轮提供批量上传及自动绑定接口 |
| 自动写入配置 | 减少活动时间、规则、奖品、任务和跳转的重复录入 | 我们输出结构化配置，飞轮接收并生成可编辑草稿 |
| 页面组件交付 | 减少纯切图带来的重复开发和效果损失 | 双方统一组件 Schema，我们输出结构和参数，飞轮负责适配和渲染 |
| 代码交付 | 满足标准组件无法覆盖的特殊页面 | 飞轮提供受控运行环境，我们按接入规范提供组件或页面代码 |

### 2. 页面体验能力

| 需求 | 说明 | 合作方式 |
|---|---|---|
| 动效支持 | 支持头图、弹窗、抽奖过程和按钮反馈 | 我们提供动效资源和播放规则，飞轮支持对应格式、触发及降级 |
| 状态切换 | 支持未参与、已参与、已完成、已领取等页面状态 | 我们提供各状态设计，飞轮根据真实业务数据驱动切换 |
| 人群差异 | 支持不同人群展示不同素材、文案、权益或主题 | 我们提供差异内容，飞轮提供人群识别、优先级和默认兜底 |

### 3. 上线保障

| 需求 | 说明 | 合作方式 |
|---|---|---|
| 预览与校验 | 确保导入后的页面和配置正确 | 飞轮返回预览结果和配置错误，我们根据结果调整 |
| 审核与发布 | 避免自动配置直接影响线上 | 飞轮保留审核、发布和权限控制 |
| 版本与回滚 | 出现问题时可以快速恢复 | 双方记录活动版本，飞轮提供回滚能力 |

## 六、希望沟通确认

1. 飞轮目前可以提供哪些接口或标准接入能力？
2. 素材、配置和页面组件分别可以怎样导入？
3. 是否支持自定义组件或整页代码接入？
4. 飞轮支持哪些动效格式和触发方式？
5. 是否已有状态切换和人群差异配置能力？
6. 是否可以选择一个真实活动共同验证完整链路？
