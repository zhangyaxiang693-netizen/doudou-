# DOU+ 活动生成器：用户视角全量测试清单

> 适用范围：当前代码中的普通用户功能。包含 PRD 导入、模板直达、蓝图确认、页面预览与编辑、模块状态、切图导出、保存版本、自动草稿、项目历史及恢复。后台组件管理不属于本清单。

## 1. 执行规则

### 1.1 每条用例必须记录

- [ ] 测试人、日期、环境、浏览器、账号、用例 ID。
- [ ] 实际结果只能填写“通过”或“失败”，不得填写“基本通过”。
- [ ] 失败时附页面截图、控制台截图、操作录屏、输入数据和下载产物。
- [ ] 涉及导出的用例必须保留原始 PNG/ZIP，不能只看导出页缩略图。
- [ ] 涉及保存恢复的用例必须记录保存前截图、版本号、恢复后截图。
- [ ] 涉及异步操作的用例必须等待操作完成，禁止在“解析中、保存中、正在生成”时提前判定。
- [ ] 每个缺陷注明首次出现步骤、稳定复现率、影响模板、影响账号和严重级别。

### 1.2 通过标准

- **P0**：主流程中断、数据丢失、越权、无法保存/恢复、无法导出、导出内容错误或严重截断。必须为 0。
- **P1**：主要编辑或状态逻辑错误、预览与导出不一致、部分模板不可用。必须为 0。
- **P2**：局部交互、样式、提示、兼容性问题。需产品确认是否阻塞。
- **P3**：低频视觉瑕疵。可记录后排期。

### 1.3 测试环境矩阵

- [ ] Chrome 最新稳定版，桌面宽屏 1440×900。
- [ ] Chrome 最新稳定版，桌面 1920×1080。
- [ ] Chrome 页面缩放 80%、100%、125%、150%。
- [ ] Safari 最新稳定版，桌面 1440×900。
- [ ] 浏览器刷新、强制刷新、关闭标签页后重新打开。
- [ ] 正常网络、慢速网络、操作中断网、恢复网络。
- [ ] 浏览器允许下载、禁止多文件下载、下载目录无写入权限三种状态。
- [ ] 普通飞书用户 A、普通飞书用户 B、未登录/登录失效账号。
- [ ] 空账号、已有 1 个项目账号、已有多个项目和多个版本账号。
- [ ] 清空站点数据后的首次访问，以及保留 IndexedDB/LocalStorage 的再次访问。

## 3. P0 主链路

### SMK-01 飞书 PRD 完整主流程

1. [ ] 用户 A 登录后进入首页。
2. [ ] 点击“上传活动 PRD”，弹窗正常打开。
3. [ ] 输入可读的模板 3 飞书文档链接，点击“获取文档内容”。
4. [ ] 操作中显示明确加载状态，按钮不得重复触发多次请求。
5. [ ] 进入“确认活动策略”，模板、人群、版本、模块和字段均正确命中。
6. [ ] 修改活动名称、头图、Big-day 发券、四档消耗返、8 个奖品、任务和流量扶持文案。
7. [ ] 点击“预览页面”，所有修改准确出现在对应页面和状态。
8. [ ] 修改页面配色、模块文案和一个业务状态。
9. [ ] 点击“保存版本”，按钮依次显示“保存中”“已保存”，随后恢复原文案且可再次点击。
10. [ ] 进入“我的”，项目名称、更新时间、PRD 标记正确。
11. [ ] 打开最新版本，恢复到预览阶段，内容、页面、状态、配色、顺序一致。
12. [ ] 进入“导出切图”，逐页数量和总数量一致。
13. [ ] 下载单张 PNG 和批量 ZIP，文件可打开、非空白、无截断、无编辑 UI。

预期：全链路无报错、无数据丢失、无错页、无错状态、无导出差异。

### SMK-02 模板直达完整主流程

1. [ ] 首页点击“上传活动 PRD”。
2. [ ] 不填写链接，选择模板 1，点击“直接进入”。
3. [ ] 系统自动建立人群 1/2/3，进入确认页。
4. [ ] 填写字段、进入预览、保存、从“我的”恢复、导出 ZIP。

预期：不依赖 PRD 服务即可完成全流程，空字段不会导致崩溃。

### SMK-03 云端失败时本地续作

1. [ ] 进入编辑后断网并修改文案。
2. [ ] 等待至少 2 秒触发自动草稿。
3. [ ] 点击“保存版本”。
4. [ ] 确认显示“已存本地”或明确提示云端失败且已保存在本地。
5. [ ] 刷新页面，进入“我的”，打开“待同步”本地草稿。
6. [ ] 恢复网络后再次保存并刷新项目列表。

预期：编辑内容不丢失；网络恢复后能生成云端版本；已同步草稿不再重复显示为待同步。
